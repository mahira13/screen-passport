# Demo-ready checklist

## Instant for anyone
- [ ] Live URL opens on a phone with no login; QR code on the slide points to it.
- [ ] First screen shows nearby filming locations within 3 seconds (location allowed or city picked).
- [ ] Tapping "Watched it" on 3 titles builds a passport live; the share card downloads/shares on iOS and Android.
- [ ] Passport URL `/p/[id]` reopens the same passport on another device.
- [ ] Search offers only our titles; an unknown title creates a request.

## Real-world features
- [ ] "I'm here" check-in tested on site (within 200 m) and refused when far away.
- [ ] Postcard frame works with a fresh photo on two different phones.
- [ ] Directions, Source and "Plan the rest with Layla" links open correctly.

## Data
- [ ] Famous titles covered near Berlin; every live location has a source and checked coordinates.
- [ ] Collections show correct progress.
- [ ] No private homes, no stills or logos.

## Numbers and backup
- [ ] Analytics show real counts for passports, shares, check-ins, postcards, Layla clicks, requests.
- [ ] Screen recording of the full flow saved offline in case Wi-Fi fails.
- [ ] 3 slides: problem + Expedia stat, live demo, numbers + business model.
